Rabbit Relay is a type-safe RabbitMQ framework for Node.js built on top of
`amqplib`.

It keeps exchanges, queues, bindings, routing keys, acknowledgements,
retries, dead-letter queues, and publisher confirms explicit while adding
the production patterns most services otherwise build themselves.

## Quick example

```ts
import {
  RabbitMQBroker,
  event,
} from "@bitspacerlabs/rabbit-relay";

const orderCreated = event("orders.created", "v1").of<{
  orderId: string;
}>();

const broker = new RabbitMQBroker("orders-service");

const sub = await broker
  .queue("orders.q")
  .exchange("orders.ex", {
    exchangeType: "topic",
    routingKey: "orders.*",
    publisherConfirms: true,
  });

await sub.produce(
  orderCreated({
    orderId: "o-1",
  })
);
```
